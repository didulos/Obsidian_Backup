## 정의

모달(modal)은 데이터나 분포에서 가장 자주 나타나는 값이거나, 다중모달 학습(multimodal learning)에서 텍스트, 이미지, 오디오 등 서로 다른 특성의 데이터 유형을 의미한다. 머신러닝 맥락에서는 후자가 더 널리 사용되며, 여러 입력 형식을 동시에 처리하는 모델 구조를 지칭한다.

## 왜 중요한가

실무에서 현실의 복잡한 문제는 단일 데이터 형식이 아닌 여러 형식의 정보를 결합해야 하므로, 모달을 활용한 통합 처리 능력은 모델 성능과 활용성을 크게 향상시킨다.

## 비유로 이해하기

사람이 영화를 이해할 때 영상, 음성, 자막을 함께 받아들이듯이, 모달은 모델이 여러 정보 채널(텍스트, 이미지, 음성)을 동시에 처리해서 더 풍부한 이해를 만드는 것이다.

## 실제 사용 예시

CLIP 모델은 이미지와 텍스트 두 개의 모달을 학습해 이미지 검색을 수행하고, ChatGPT의 멀티모달 버전은 이미지와 텍스트를 함께 입력받아 분석한다.
