## 정의

정보나 아이디어를 간결한 단문(bullet point) 형태로 나열하여 표현하는 방식이다. 각 항목은 주로 기호(•, -, *, 등)로 시작하며 핵심 내용만 담아 빠르게 이해할 수 있도록 구조화한다.

## 왜 중요한가

복잡한 정보를 명확하고 읽기 쉬운 형태로 전달하므로, 보고서, 프레젠테이션(presentation), 문서화에서 의사소통 효율을 크게 높인다. 특히 AI/ML 프로젝트의 요구사항 정의, 결과 공유, 의사결정 시간 단축에 필수적이다.

## 비유로 이해하기

길고 복잡한 소설을 읽는 대신, 책의 목차나 핵심 줄거리를 몇 줄로 정리한 것과 같다. 필요할 때 빠르게 전체 내용을 파악할 수 있다.

## 실제 사용 예시

모델 성능 평가 결과: "• 정확도 95% 달성 • 추론 시간 200ms 개선 • 메모리 사용량 30% 감소" / 프로젝트 마일스톤: "• 데이터 수집 완료 • 모델 학습 중 • 배포 예정"
